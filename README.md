# RoboClaw

Live industrial robot labs you can control from the browser.

## Enter the experience
→ [Open Host Concierge](https://roboclawlab.com/labs/RoboClaw_Host_Concierge.html)

Star this repo, then use **Login with GitHub** in the Host to join the live queue.

## What you’ll experience
- Real KUKA / ABB robot motion (not a simulation)
- 5-minute exclusive sessions
- Camera, lighting, and show controls
