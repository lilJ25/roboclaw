# Public Manufacturer Spec Sheets & Data

These are publicly available official or widely distributed manufacturer documents. Links point to stable public sources (Digi-Key hosted, ABB library, etc.). Students and parents can download them for deeper study.

## KUKA KR 10 R1100-2
- Official-style technical data sheet (English):  
  https://media.digikey.com/pdf/Data%20Sheets/KUKA%20Robotics%20PDFs/KR_10_R1100-2.pdf  
  (Maximum reach 1101 mm, max payload 10.9 kg, repeatability ±0.02 mm, axis ranges, IP65/IP67, KR C4 compact controller, cycle-time reference)

- Additional public datasheet versions and workspace graphics are commonly available via KUKA partner sites and industrial distributors.

## ABB IRB 120
- Official Product Specification (IRB 120, IRC5, Document ID 3HAC035960-001, Revision W):  
  https://library.e.abb.com/public/429d251dbce44b049ba7d6107a422de0/3HAC035960%20PS%20IRB%20120-en.pdf  
  (Full structure, load diagrams, motion ranges, performance data per ISO 9283, installation, options)

- Compact datasheet / brochure style summary:  
  https://library.e.abb.com/public/cb71c9082357490ca3ba2a6befcfdce1/Datenblatt_IRB120_lowres.pdf

These documents are the authoritative sources for the specifications used in the educational materials above.
