# KUKA KR 10 R1100-2

Compact 6-axis industrial robot from the Agilus-2 family.

## Key Specifications (manufacturer data)
| Parameter | Value |
|-----------|-------|
| Maximum reach | 1101 mm |
| Maximum payload | 10.9–11.1 kg |
| Rated payload (optimized dynamics) | 5 kg |
| Pose repeatability (ISO 9283) | ± 0.02 mm |
| Number of axes | 6 |
| Robot weight | approx. 55–56.5 kg |
| Footprint | 208 mm × 208 mm |
| Mounting positions | Floor, ceiling, wall, any angle |
| Protection rating | IP65 / IP67 |
| Ambient temperature (operation) | 0 °C to 45 °C |
| Controller | KR C4 compact / KR C5 micro |
| Teach pendant | KUKA smartPAD |
| Cycle time (reference) | 140 cycles/min (25/305/25 mm path, 1 kg) |

## Axis Motion Ranges
- A1: ±170°
- A2: –190° / +45°
- A3: –120° / +156°
- A4: ±185°
- A5: ±120°
- A6: ±350°

## Typical Applications
Additive manufacturing, applying/painting/gluing, arc welding, assembly, handling, machine loading/unloading, measuring/inspection, palletizing/packaging, pick-and-place.

The KR 10 R1100-2 is widely used where high speed, high repeatability, and a small footprint are required in electronics, packaging, and light assembly cells.
