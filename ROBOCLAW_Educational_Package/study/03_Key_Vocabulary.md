# Key Vocabulary for RoboClaw Labs

| Term | Simple Definition |
|------|-------------------|
| Axis | One of the rotating joints of a robot arm |
| Reach | The farthest distance the robot can extend |
| Payload | The maximum weight the robot can safely carry |
| Repeatability | How accurately the robot returns to the same position |
| Articulated robot | A robot with multiple rotating joints (like a human arm) |
| Industrial robot | A programmable machine used in factories and labs |
| Controller | The computer that tells the robot how to move |
| End effector | The tool or gripper attached to the end of the robot arm |
| Cycle time | How long it takes the robot to complete one task and return |
| Teach pendant | The handheld device used to program or move the robot |
