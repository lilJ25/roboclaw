# ROBOCLAW Lab Educational Package

Complete seed content + Parent & Student Toolkit for ROBOCLAW Progressive UI / Homeschool labs.

**Branded ROBOCLAW** • Matches progressive UI aesthetic • Ready for parent forks

This repository contains accurate reference materials for the industrial robots used in the labs:

- **KUKA KR 10 R1100-2** (Agilus series)
- **ABB IRB 120**

Plus a full educational toolkit designed to sit around the live 10-minute lab experience.

---

## Package Contents

### Core Reference
- `docs/` – Robot specifications, educational notes, public manufacturer PDF links
- `history/` – Mini-book: History of Industrial Robotics (with citations)
- `config/roboclaw_lab_seed.json` – Lightweight seed file for meaningful forks

### Parent & Student Toolkit (`study/`)
- Pre-lab and post-lab reading packets
- Key vocabulary
- Matching quiz
- Printable short test (black-and-white / ink-saving)
- Crossword & word search
- Extended factoid list
- Educational games + full-page printable games
- Mini info books
- Answer key

### Flagship Resource
- **ROBOCLAW_How_to_Be_a_Roboticist.pdf** – 25-page full-color educational mini-book  
  Designed to encourage students to pursue careers in industrial robotics.  
  Professional dark-tech aesthetic matching the progressive UI look.

---

## Design Notes
- High-contrast text and minimal graphics for clean black-and-white or grayscale printing where appropriate
- Quizzes and tests intentionally sparse to save ink
- Mini-books and reading packets short for focused attention
- Games require almost no preparation
- Overall style is clean, professional, and consistent with a serious robotics learning environment

All technical and historical information is drawn from manufacturer specifications and established historical sources (IEEE Spectrum, IFR, KUKA & ABB company records).
